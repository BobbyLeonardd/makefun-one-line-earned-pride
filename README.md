One line of text for make.fun's "One Line of Earned Pride" bounty: a night cleaner who has just finished waxing a corridor and walks it in his socks before the chairs go back on the desks.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR`, `$OUTPUT_DIR` or `/output`.
